Was ist das?

OpenAI · ChatGPT15. Juli 2026

Custom Instructions: Zeichenlimit auf 5.000 verdreifacht

Was ist das?

„Custom Instructions" sind ein persönlicher Anweisungstext (ähnlich einem System-Prompt), den ChatGPT bei jedem neuen Chat automatisch berücksichtigt — z. B. Angaben zu deinem Beruf, bevorzugten Ton oder Hintergrundwissen. Das Zeichenlimit wurde von 1.500 auf 5.000 Zeichen erhöht, du kannst also deutlich ausführlicher werden.

Warum relevant

Für alle, die ChatGPT regelmäßig für wiederkehrende Aufgaben nutzen (z. B. immer im gleichen Schreibstil, mit Firmenkontext) — spart, dieselben Vorgaben in jedem Prompt zu wiederholen.

So nutzt du's

Einstellungen → Personalization → Custom Instructions öffnen und die beiden Felder („Was soll ChatGPT über dich wissen" / „Wie soll ChatGPT antworten") ausführlicher ausfüllen — z. B. Rolle, Tonfall, Formatierungswünsche, wiederkehrende Constraints.

MCP, Cursor, Claude Code — zum Nachbauen

Kurz erklärt: MCP (Model Context Protocol) = offener Standard von Anthropic, der KI-Modellen erlaubt, sich einheitlich mit externen Tools und Datenquellen zu verbinden — wie ein „USB-Anschluss" für KI-Agenten. Model Context Protocol28. Juli 2026

MCP-Spezifikation 2026-07-28: „Stateless Core" + Extensions

Was ist das?

Die größte Überarbeitung des MCP-Standards seit seiner Einführung. GitHub hat seinen offiziellen MCP-Server bereits vorab auf das neue Protokoll umgestellt.

Warum relevant

Für alle, die eigene MCP-Server betreiben oder in Claude Code/Cursor integrieren (Entwickler, DevOps) — einfacheres Skalieren, aber Breaking Changes bei eigenen Implementierungen.

So nutzt du's

Bei eigenen MCP-Servern: SDK auf die neue Spezifikation aktualisieren und auf zustandslose Anfrageverarbeitung umstellen. Bei reiner Nutzung fremder MCP-Server (z. B. GitHub): einfach die Server-Version aktualisieren, die Konfiguration in Claude Code/Cursor bleibt unverändert (abwärtskompatibel).
